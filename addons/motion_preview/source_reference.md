# 모션 공급자의 기준 모델 지정 (1.3.1)

모션 전용 FBX의 RESET은 공격의 첫 프레임일 수 있습니다. RESET이 있다는 사실만으로 제작자의 중립 bind 자세가 복원되지는 않습니다. 그 자세를 중립 rest로 리타게팅하면 같은 제작 모델에서도 몸통/팔다리가 틀어질 수 있습니다.

프로젝트 설정의 `addons/motion_preview/retarget/source_models` Dictionary에 모션 폴더와 공급자 기준 모델 FBX·GLB를 연결합니다. 키는 `res://.../`로 끝나는 폴더 경로, 값은 해당 모션을 제작한 기준 모델입니다. 여러 키가 일치하면 가장 긴 경로를 사용합니다. 이 값은 화면에서 선택하는 출력 모델과 별개이며 모션/출력 모델 원본을 수정하지 않습니다.

```ini
[addons]
motion_preview/retarget/source_models={
"res://assets/vendor/motions/": "res://assets/vendor/model/character.FBX"
}
```

공급 모델의 본 이름·역할·부모 계층이 임포트된 모션과 일치할 때만 기준 골격을 복사합니다. Exporter 같은 비변형 보조 노드 차이는 무시합니다. 불일치하거나 모델이 삭제된 경우 오류를 표시하고 잘못된 기준으로 재생하지 않습니다. 현재 선택한 출력 모델에서 자동으로 bind 자세를 추측하지 않습니다.

고급 임포트에서 본 이름을 표준화한 모션에는 원본 좌표계 rest를 덮어쓰지 않고 기존 정규화 경로를 유지합니다. 원본 이름인 모션과 정규화 모션을 같은 참조 모델로 재해석하지 않습니다. 대응 설정이 없는 패키지는 기존 RESET 동작을 유지하므로 공급자가 기준 모델을 별도로 제공한 경우 그 모델을 명시해야 합니다.

이 수정은 RESET 자동 생성 설정이나 원본 클립 키를 변경하지 않습니다. 기준 모델이 신뢰할 수 없는 경우 임의의 첫 프레임/각도로 고치는 기능은 아닙니다. 대표 Paladin RPG Sword-Attack-L4의 직접 재생과 미리보기 비교로 회귀를 확인합니다. 구매 에셋은 애드온/ZIP에 포함하지 않습니다.

루트 모션 기준 노드는 skin bind 축과 다른 좌표계로 내보내질 수 있습니다. 모션의 Root 기준을 유지하면서 변형 본의 모델 공간 bind 자세를 로컬 계층으로 재분해합니다. 같은 기준 모델에 적용하는 경우는 보존한 본 이름·부모·rest·공간 서명으로 확인하여 원본 키를 직접 재생합니다. 본 이름만 같다는 이유로 직접 재생하지 않습니다.
