# Motion Preview 1.2.0 설계·검증 기록

2026-10-18, Godot 4.7.2 (`ed1daf0bf`), macOS.

## 배경과 범위

외부 소비 프로젝트의 `skill_editor` 0.1.0은 Motion Preview 1.1.2를 상속하고 내부 모델·플레이어·메뉴·슬라이더 필드를 사용했다. 소비 코드 `skill_preview.gd`, `skill_panel.gd`, `timing_bar.gd`, 해당 README와 `tests/skill_editor_test.gd`, `docs/PLUGINS.md`를 읽어 필요한 계약을 확인했다. 기존 뷰포트/카메라/스크러빙을 복제하지 않고 외부 시점 편집기가 같은 재생 코어를 사용하도록 공개 메서드와 신호를 추가했다.

시작 시 개발 저장소는 커밋 `601db17`이며 작업 트리는 깨끗했다. 프로젝트/상위 경로에 적용할 AGENTS.md는 발견되지 않았다. 소비 프로젝트 파일과 설치본은 읽기만 했으며 이 릴리스에서 수정하지 않는다. 게임 쪽 설치 명세 갱신과 실제 어댑터 이전은 다음 작업이다. 로컬 커밋과 ZIP까지만 생성하며 푸시하지 않는다.

## 결정

- 안전 모델 경로: 기존 Catalog 정책(스크립트 없음·하나의 골격·실제 메시)과 Binding.bind의 골격 대응/리타게팅을 그대로 사용한다.
- 준비된 대상 경로: 게임 어댑터가 독립 외형 인스턴스를 정리하고 애니메이션 루트와 라이브러리 사전을 전달한다. 원래 AnimationPlayer는 보존하지 않고 내부의 수동 플레이어를 사용하므로 카메라와 재생 흐름을 하나로 유지한다.
- 이미 등록/리타게팅된 모션은 경로를 유지한다. 복사본의 본 트랙만 재생하며 추가 리타게팅을 만들지 않는다. 기존 엔진 RetargetModifier는 유지할 수 있다. 필요하면 `pose_updated` 콜백으로 어댑터가 구동 골격의 수동 갱신을 요청한다.
- 안전성 검사는 스크립트/믹서/충돌/카메라/오디오/보조 modifier를 거부하지만 범용 보안 샌드박스는 아니다. 어댑터가 게임 실행과 부작용을 제거할 책임을 진다.
- 준비된 대상 설치 실패는 이전 미리보기를 보존하고 소유권을 받지 않는다. 성공하면 교체·해제·컨트롤 파괴 시 플러그인이 대상과 재생 코어를 해제한다. 일반 모델 로드는 기존처럼 이전 대상을 먼저 비운다.
- 라이브러리와 Animation을 복제하여 반복/트랙 설정을 변경한다. 메시·머티리얼·Skin 원본 Resource를 수정하지 않는다. 준비된 라이브러리는 스냅샷이며 변경 시 새 대상을 전달한다. 일반 라이브러리는 변경 신호를 구독하고 교체 시 이전 연결을 해제한다.
- 시간은 실제 클립의 초 단위이다. 반복 클립의 끝 스크러빙에서 엔진이 0초로 감싸는 동작을 복사본의 반복 모드를 일시적으로 해제하여 보정했다. 비반복 재생은 끝에서 멈춘다.
- 공통 코드에 게임 전용 리소스, visual 추출 경로, PC 씬, 전투/시점 저장 형식, XZ 범위 판정 규칙을 넣지 않는다. 이들은 게임 어댑터와 시점 편집기에 남는다.

계약, 신호, 소비 예제, 1.1.2 필드별 이전 표는 배포 ZIP에도 포함되는 [API.md](../addons/motion_preview/API.md)를 따른다.

## 검증

다음 검사는 외부 구매 에셋 없이 생성 모델/클립만 사용한다. 정상 종료 루틴과 `--quit-after 1200` 상한을 사용한다. portability Python 래퍼에는 45초 프로세스 제한도 있다.

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --log-file /tmp/motion-api-final.log --quit-after 1200 --script tests/motion_preview_api.gd
python3 tests/check_motion_preview_portability.py /Applications/Godot.app/Contents/MacOS/Godot
python3 tests/check_motion_preview_portability.py /Applications/Godot.app/Contents/MacOS/Godot --render
```

- API 검사: `MOTION_API_COMPLETE checks=51 failures=0`, 종료 코드 0, 최종 실행에 엔진/스크립트 오류 없음. 빈 상태, 실제 .8초 길이, 선택/재생/정지/배속/반복/끝 자세/스크러빙, 기존 엔진 modifier의 변형 골격 갱신, 원본 반복·트랙 보존, 메서드 트랙 미실행, 잘못된 인스턴스/경로/라이브러리 거부, 소유권·교체·해제·종료, 라이브러리 교체/연결 해제, 안전 로더로 복귀, 신호를 검사한다.
- headless 인스펙터 통합: `PORTABLE_EDITOR_COMPLETE checks=24 failures=0`.
- 정상 macOS GUI 인스펙터 통합: `PORTABLE_EDITOR_COMPLETE checks=28 failures=0`. 최초 구도/초기화/좁은 폭 PNG를 열어 전체 생성 메시가 프레임 안에 들어오고 구도가 유지되는 것을 확인했다. 경고 표시/엔진 리타게팅 검사도 포함한다.
- 로그와 PNG: 로컬 `output/motion_preview_checks/`. API 최종 로그도 그 폴더에 보관한다.
- 초기 샌드박스 headless 실행은 macOS 인증서 조회 오류를 출력했다. 최종 검사는 정상 권한 환경에서 수행했다. GUI는 처음부터 정상 macOS 환경에서 실행했으며 NSApplication 충돌을 재현하지 않았다.

미검증: 소비 프로젝트의 실제 캐릭터/모션과 새 API 소비 코드 이전, 모든 임포트 형식/골격의 호환성, 게임 전투의 판정/피해/FX, 보조 머리·치마 물리. 기존 engine modifier의 렌더링/변형은 다음 엔진 프레임에 완료될 수 있으며 `time_changed`는 렌더 완료 신호가 아니다. 전체 회귀를 반복하지 않고 변경에 직접 관련된 API와 기존 인스펙터 통합만 확인했다.

## 배포

`addons/motion_preview/plugin.cfg`를 1.2.0으로 올리고 기존 `python3 release.py`로 `output/motion_preview-1.2.0.zip`을 생성한다. ZIP은 플러그인 코드·API.md·MIT LICENSE만 포함하며 구매 모델/모션과 개발 테스트는 포함하지 않는다. ZIP 무결성/내용과 SHA-256은 릴리스 완료 시 확인한다.
